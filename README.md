# budgetmates

Учет расходов, доходов и кредитных карт из банковских PDF. Поддерживаются форматы личных выписок Альфа-Банка, ВТБ и Ozon Банка, с которых началась разработка.

## Запуск

```sh
bun install --frozen-lockfile
bun run dev
```

Проверки и production-сборка:

```sh
bun run lint
bun run build
bun run preview
```

### Dev на Android

При подключённом ADB запусти Vite на loopback и пробрось тот же порт на телефон.

```sh
adb reverse tcp:5173 tcp:5173
bun run dev --host 127.0.0.1 --port 5173 --strictPort
```

В Chrome на телефоне открой `http://localhost:5173/`. Хранилище привязано к профилю браузера и адресу, поэтому на новом порту или устройстве оно начинается пустым. Для WebAuthn PRF нужен совместимый браузер и ключ доступа.

Для установки на телефон размести содержимое `dist/` на своём HTTPS-хосте. Открой адрес в браузере телефона и выбери установку приложения или добавление на главный экран. После первого успешного открытия подожди, пока браузер завершит загрузку ресурсов, тогда приложение сможет открываться офлайн.

## Импорт и хранение

В разделе «Импорт» выбери PDF, проверь распознанные операции и сохрани их. Повторный импорт дополняет данные счёта и сохраняет ручные категории. Неподтверждённые HOLD из выписок Альфы отмечаются как «В обработке». После импорта совпавшей проводки или более свежей выписки за тот же день резерв обновляется.

В «Операциях» доступны фильтры доходов, расходов и своих переводов. Свои переводы и служебные проводки по кредиткам исключаются из итогов. Неопознанные переводы доступны через «Фильтры». Номер для распознавания собственных переводов задаётся через «Ещё → Номер для СБП». Для сопоставления хранятся криптографические метки и маска своего номера. Чтобы учесть компенсацию, свайпни поступление влево и выбери «К расходу». Связь уменьшает исходный расход и исключает компенсацию из доходов.

Операции, снимки по кредиткам и сохранённые расчёты шифруются в браузере через AES-256-GCM. Для нового хранилища используется ключ доступа с WebAuthn PRF. Создание и подтверждение ключа запускаются отдельно. Можно использовать встроенный способ браузера или совместимый USB/NFC-ключ. При встроенном входе браузер может предложить синхронизируемого провайдера, например Google Password Manager. Для WebAuthn нужен HTTPS-домен или `localhost`. В старых парольных хранилищах используется PBKDF2-SHA-256. PDF обрабатываются в браузере и не сохраняются приложением. Хранилище блокируется по кнопке или после пяти минут бездействия. Очистка данных сайта удаляет локальное хранилище. Восстановить забытый пароль или потерянный ключ доступа средствами приложения нельзя.

### Перенос с прежнего адреса

Данные на `127.0.0.1` и `localhost` хранятся отдельно. В старом парольном хранилище открой «Способы входа» (иконка отпечатка) и скачай зашифрованную копию. На новом адресе на экране настройки выбери «Восстановить из файла» и введи прежний пароль. Затем через «Способы входа» включи отпечаток или PIN устройства. Прежний пароль останется резервным способом. Экспорт для переноса доступен для парольных хранилищ до включения входа устройством.

## Кредитки

Сумма для сохранения грейса, общий долг и минимальный платёж берутся из последней подходящей выписки. Можно добавить импортированный счёт и указать свою дату платежа. Напоминание видно на «Обзоре» за день до срока. Событие для системного календаря экспортируется кнопкой «В календарь».

## Расчёт счёта

В «Расчёте» добавь участников и позиции. Цена за штуку умножается на количество и добавляется каждому выбранному участнику. Сохранённый счёт можно привязать к проведённому расходу в той же валюте, если сумма совпадает с итогом или твоей долей. В статистике учитывается банковская операция, а связь хранится в записи расчёта. Расчёт перенесён из [bill-mates](https://github.com/belowevolve/bill-mates).
