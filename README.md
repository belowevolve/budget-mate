# budget mate

Учет расходов, доходов и кредитных карт из банковских PDF. Поддерживаются форматы личных выписок Альфа-Банка, ВТБ и Ozon Банка, с которых началась разработка.

## Запуск

```sh
bun install --frozen-lockfile
bun run dev
```

Проверки и production-сборка:

```sh
bun run lint
bun run build
bun run preview
```

### Dev на Android

При подключённом ADB запусти Vite на loopback и пробрось тот же порт на телефон.

```sh
adb reverse tcp:5173 tcp:5173
bun run dev --host 127.0.0.1 --port 5173 --strictPort
```

В Chrome на телефоне открой `http://localhost:5173/`. Хранилище привязано к профилю браузера и адресу, поэтому на новом порту или устройстве оно начинается пустым. Для WebAuthn PRF нужен совместимый браузер и ключ доступа.

Для установки на телефон размести содержимое `dist/` на своём HTTPS-хосте. Открой адрес в браузере телефона и выбери установку приложения или добавление на главный экран. После первого успешного открытия подожди, пока браузер завершит загрузку ресурсов, тогда приложение сможет открываться офлайн.

## Импорт и хранение

В разделе «Импорт» выбери PDF, проверь распознанные операции и сохрани их. Для ВТБ подходят выписки по карте и по счёту. Повторный импорт дополняет данные счёта и сохраняет ручные категории. Неподтверждённые операции из выписок Альфы и кредитных выписок ВТБ отмечаются часами. Резерв обновляется по совпавшей проводке или более свежей выписке с полным списком неподтверждённых операций за этот период.

В «Операциях → Переводы» видны свои переводы и привязанные компенсации. Если по выпискам не удалось определить, чей перевод, там появляется вкладка «Неопознанные». Такие операции можно отметить как свои или учесть, выбрав категорию. До выбора их суммы исключаются из бюджета, как и свои переводы и служебные проводки по кредиткам. Номер для распознавания собственных переводов задаётся через «Настройки → Номер для СБП». Для сопоставления хранятся криптографические метки и маска своего номера. Нажатие на иконку операции или длинный свайп расхода влево открывает выбор категории. Чтобы учесть компенсацию, свайпни поступление влево и выбери «К расходу». Связь уменьшает исходный расход и исключает компенсацию из доходов.

Операции, снимки по кредиткам и сохранённые расчёты шифруются в браузере через AES-256-GCM. Для нового хранилища используется ключ доступа с WebAuthn PRF. Браузер подтверждает вход отпечатком, PIN или другим системным способом, доступным на устройстве. При первой настройке некоторые провайдеры требуют дополнительное подтверждение. Можно использовать совместимый USB/NFC-ключ. При встроенном входе браузер может предложить синхронизируемого провайдера, например Google Password Manager. Для WebAuthn нужен HTTPS-домен или `localhost`. В старых парольных хранилищах используется PBKDF2-SHA-256. PDF обрабатываются в браузере и не сохраняются приложением. Хранилище блокируется через «Настройки → Заблокировать» или после пяти минут бездействия. Очистка данных сайта удаляет локальное хранилище. Для восстановления данных после потери доступа понадобится резервная копия и её код.

### Перенос с прежнего адреса

Данные на `127.0.0.1` и `localhost` хранятся отдельно. В «Настройки → Резервная копия» можно скачать зашифрованный файл `.bmvault` с любым способом входа. Сохрани файл и показанный код отдельно. На новом адресе на экране настройки выбери «Восстановить копию», укажи файл и введи его код. Для старых копий используй прежний пароль. После восстановления отпечаток или PIN устройства можно подключить через «Настройки → Способы входа».

## Кредитки

Сумма для сохранения грейса, общий долг и минимальный платёж берутся из последней подходящей выписки. Можно добавить импортированный счёт и указать свою дату платежа.

Открой «Настройки → Уведомления браузера» и нажми «Разрешить». Кнопка «Проверить» показывает проверочное системное уведомление. Приложение проверяет сроки после открытия хранилища, при возвращении на вкладку и пока вкладка продолжает выполнять код. За день до платежа системное уведомление показывает банк и маску счёта. Нажатие на уведомление открывает «Кредитки». Кнопка с календарём рядом с платежом открывает редактор события в Google Календаре. Для других календарей в настройках платежа можно скачать событие в формате `.ics` с напоминанием за день. [Ограничения расписания в Chrome](https://developer.chrome.com/docs/web-platform/notification-triggers)

## Расчёт счёта

В «Расчёте» выбери участников и добавь позицию через нижнюю панель. Для каждого участника видны свои позиции и итог. Цену и количество можно менять прямо в строке. Сохранённый счёт можно привязать к расходу, в том числе к операции «В обработке», если валюта и сумма совпадают с итогом или твоей долей. В статистике учитывается банковская операция, а связь хранится в записи расчёта. Экран основан на [bill-mates](https://github.com/belowevolve/bill-mates).
